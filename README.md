# Digikala Warehouse Android

Standalone Android WebView APK for the warehouse operator.

- 225 real products embedded from the V3 product bank.
- Operator searches by Product Code (PC).
- Inventory and recent searches are stored locally on the device.
- No server or monthly hosting required for core operation.
- Missing Product Codes are intentionally left blank; no mappings are invented.

## Build
Push to GitHub. GitHub Actions builds `app-release.apk`.
